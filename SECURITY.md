# Security and Responsible Deployment

- Never commit API keys or personal datasets.
- Store provider keys in Streamlit/GitHub secrets.
- Do not enter sensitive personal, health, student, proprietary, or regulated data into a public deployment unless governance and access controls are appropriate.
- IdeaForge is decision support, not an autonomous medical, legal, financial, safety, admissions, employment, or investment decision-maker.
- Review third-party provider data-handling terms before enabling live LLM suggestions.
- Report vulnerabilities privately to the repository owner rather than publishing secrets or exploitable details.
